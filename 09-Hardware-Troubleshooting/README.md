# Hardware Troubleshooting

## Overview

This section documents a real-world hardware troubleshooting case involving diagnosing and repairing a desktop PC issue.

The purpose of this case study was to demonstrate fault finding, component diagnosis, hardware compatibility checks, and problem resolution.

---

## Issue Identified

The PC was experiencing:

- Unexpected shutdowns.
- No display output after rebuild.
- Hardware compatibility issues.

---

## Troubleshooting Completed

- Inspected internal PC components.
- Identified damaged CPU socket pins.
- Determined motherboard replacement was required.
- Researched compatible replacement components.
- Rebuilt the system.
- Diagnosed RAM compatibility issue.
- Verified successful system operation.
