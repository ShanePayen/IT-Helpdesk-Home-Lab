# Active Directory Setup

## Overview

This section covers the installation and configuration of Active Directory Domain Services (AD DS) on the Windows Server virtual machine.

The purpose of this stage was to create a domain environment that can be used to manage users, computers, groups, and security policies.

---

## Completed Tasks

- Installed Active Directory Domain Services.
- Promoted Windows Server to a Domain Controller.
- Created a new domain environment.
- Verified Active Directory configuration.

---

## Tools Used

- Windows Server
- Server Manager
- Active Directory Domain Services
- Active Directory Users and Computers
- PowerShell

---

## Skills Demonstrated

- Active Directory administration
- Domain Controller deployment
- Identity management
- Windows Server roles and features
