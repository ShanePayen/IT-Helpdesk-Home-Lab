# Helpdesk Ticketing Workflow Documentation

## Overview

This document explains a simulated helpdesk ticket management workflow created using a spreadsheet.

The purpose was to practise how IT support teams manage incidents from initial reporting through to resolution.

A ticketing system allows support teams to:

- Track user issues.
- Prioritise incidents.
- Record troubleshooting steps.
- Maintain support history.
- Monitor outstanding tasks.

---

# Ticket Lifecycle

The workflow followed these stages:

## 1. Ticket Creation

A new issue was recorded with important information.

Information captured:

- Ticket ID.
- Date reported.
- User/requester.
- Issue description.
- Category.
- Priority.
- Status.

---

## 2. Issue Categorisation

Tickets were grouped into categories to make troubleshooting easier.

Examples:

### Hardware

Examples:

- PC not powering on.
- Component failure.
- Display issues.

### Software

Examples:

- Application errors.
- Installation problems.
- Configuration issues.

### Account Access

Examples:

- Password resets.
- User account problems.
- Permission issues.

### Network

Examples:

- Connectivity issues.
- DNS problems.
- DHCP issues.

---

## 3. Priority Assignment

Issues were assigned priority levels based on impact.

### High Priority

Examples:

- User unable to work.
- System outage.
- Critical hardware failure.

### Medium Priority

Examples:

- Application issues.
- Access problems affecting some tasks.

### Low Priority

Examples:

- General requests.
- Non-critical improvements.

---

# Example Ticket

## Ticket ID

HD-001

## Category

Hardware

## Issue

Desktop computer shutting down unexpectedly.

## Investigation

- Checked hardware components.
- Inspected CPU socket.
- Reviewed motherboard condition.
- Checked component compatibility.

## Resolution

- Replaced damaged motherboard.
- Installed compatible RAM.
- Tested system functionality.

## Status

Closed.

---

# Ticket Documentation Process

Each ticket included:

## Problem

Description of the reported issue.

## Investigation

Steps taken to identify the cause.

## Resolution

Actions completed to fix the problem.

## Outcome

Confirmation that the issue was resolved.

---

# Benefits of Ticket Documentation

Maintaining accurate ticket records helps IT teams:

- Improve troubleshooting speed.
- Identify repeated issues.
- Track workload.
- Maintain technical knowledge.
- Provide better user support.

A simulated helpdesk ticket workflow was created to demonstrate understanding of incident management processes.

The workflow shows how IT technicians record, investigate, resolve, and document technical issues.
