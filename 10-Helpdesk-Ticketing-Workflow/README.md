# Helpdesk Ticketing Workflow

## Overview

This section documents a simulated helpdesk ticket management workflow created using a spreadsheet.

The purpose of this workflow was to practise how IT support teams record, track, prioritise, troubleshoot, and resolve user issues.

---

## Completed Tasks

- Created a spreadsheet-based ticket tracking system.
- Recorded support issues.
- Categorised incidents.
- Assigned priorities.
- Documented troubleshooting steps.
- Recorded resolutions.
- Tracked ticket status.

---

## Ticket Workflow

The process followed:

1. Ticket created.
2. Issue categorised.
3. Priority assigned.
4. Troubleshooting performed.
5. Resolution documented.
6. Ticket closed.

---

## Tools Used

- Spreadsheet-based ticket tracker.
- Windows troubleshooting tools.
- Active Directory lab environment.
- PowerShell.

---

## Skills Demonstrated

- Helpdesk workflow understanding.
- Incident management concepts.
- Issue prioritisation.
- Technical documentation.
- Troubleshooting records.
