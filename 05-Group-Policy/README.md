# Group Policy Configuration

## Overview

This section covers the configuration and testing of Group Policy settings within the Active Directory environment.

Group Policy allows administrators to apply security settings, restrictions, and configuration changes across users and computers in a domain.

---

## Completed Tasks

- Accessed Group Policy Management.
- Reviewed domain policies.
- Configured password requirements.
- Configured account lockout settings.
- Verified policy configuration using PowerShell.

## Tools Used
