# User Onboarding and Offboarding Documentation

## Overview

This document explains the onboarding and offboarding processes used by IT support teams to manage user accounts throughout the employee lifecycle.

In a business environment, helpdesk technicians are responsible for creating accounts, assigning access, troubleshooting user issues, and securing accounts when employees leave.

---

# Objective

The objectives of this process were:

- Understand how new employee accounts are created.
- Assign appropriate access permissions.
- Follow a structured account management process.
- Secure accounts during employee departures.

---

# Environment

## Systems Used

- Active Directory
- Windows Server Domain Controller
- Microsoft 365 Administration Workflow

---

# User Onboarding Process

## Step 1: Receive New User Request

The IT team receives a request containing information about the new employee.

Information required:

- Employee name.
- Job role.
- Department.
- Required access.
- Start date.

---

## Step 2: Create User Account

The user account is created within Active Directory.

Process:

1. Open Active Directory Users and Computers.
2. Select the correct organisational unit.
3. Create a new user account.
4. Enter user details.
5. Set an initial password.
6. Configure account settings.

---

## Step 3: Assign Security Groups

The user is added to the required security groups based on their role.

Examples:

- Department groups.
- Shared resource access.
- Application permissions.

Security groups allow administrators to manage access efficiently.

---

## Step 4: Configure User Access

Access is configured depending on the employee's requirements.

Examples:

- Network resources.
- Shared folders.
- Microsoft 365 services.
- Communication tools.

---

## Step 5: Verify Account

The account is checked to confirm:

- User can sign in.
- Correct permissions are applied.
- Required services are available.

---

# User Offboarding Process

## Step 1: Receive Employee Leaving Request

IT receives notification that an employee is leaving the organisation.

Information checked:

- Employee account.
- Leaving date.
- Required access removal.

---

## Step 2: Disable User Account

The user account is disabled to prevent further access.

Process:

1. Open Active Directory Users and Computers.
2. Locate the user account.
3. Disable the account.

---

## Step 3: Remove Access Permissions

Access is removed from:

- Security groups.
- Shared resources.
- Applications.
- Company systems.

---

## Step 4: Secure Company Data

Depending on company policy:

- Transfer ownership of files.
- Preserve required emails.
- Secure user data.

---

## Step 5: Remove Microsoft 365 Access

Microsoft 365 actions may include:

- Blocking sign-in.
- Removing licences.
- Removing access permissions.
- Managing mailbox access.
