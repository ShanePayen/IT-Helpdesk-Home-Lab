# PowerShell Administration

## Overview

This section covers the use of PowerShell commands to manage, verify, and troubleshoot the Active Directory lab environment.

PowerShell is commonly used by IT administrators and helpdesk technicians to automate tasks, check system information, and manage Windows environments.

## Completed Tasks

- Used PowerShell to verify system information.
- Checked Active Directory domain details.
- Verified user information.
- Checked password policy settings.
- Applied Group Policy updates.
