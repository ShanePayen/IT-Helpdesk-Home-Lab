# Microsoft 365 Admin Workflow Documentation

## Overview

This document explains common Microsoft 365 administration workflows used by IT support teams.

Microsoft 365 administrators manage user accounts, licences, permissions, and services such as Outlook, Teams, OneDrive, and SharePoint.

---

# Objective

The objectives of this workflow were:

- Understand Microsoft 365 user management.
- Understand licence assignment.
- Document onboarding and offboarding processes.
- Understand account security and access management.

# Microsoft 365 User Onboarding Process

## Step 1: Receive New User Request

The IT team receives information about the new employee.

Required information:

- Employee name.
- Job role.
- Department.
- Required services.
- Start date.

---

## Step 2: Create Microsoft 365 User Account

Process:

1. Open Microsoft 365 Admin Centre.
2. Navigate to Users.
3. Select Active Users.
4. Select Add User.
5. Enter user information.
6. Create the account.

---

## Step 3: Assign Licence

After creating the user, an appropriate Microsoft 365 licence is assigned.

Examples of licences used by organisations include:

- Microsoft 365 Business Standard.
- Microsoft 365 Business Premium.
- Microsoft 365 E3.
- Microsoft 365 E5.

The assigned licence determines which services the user can access.

---

## Step 4: Configure User Access

User access can be configured for services such as:

- Outlook mailbox.
- Microsoft Teams.
- OneDrive storage.
- SharePoint sites.

Access should be based on the user's role and business requirements.

---

## Step 5: Verify Account

The account should be tested to confirm:

- User can sign in.
- Licence has been applied.
- Required services are available.

---

# Microsoft 365 User Offboarding Process

## Step 1: Receive Leaving Request

IT receives notification that an employee is leaving.

Information checked:

- User account.
- Leaving date.
- Required data retention.

---

## Step 2: Block Sign-In

The user account is blocked to prevent unauthorised access.

---

## Step 3: Remove Licence

The assigned Microsoft 365 licence is removed.

This prevents unnecessary licence costs after the account is no longer required.

---

## Step 4: Manage User Data

Depending on company policy:

- Transfer OneDrive files.
- Manage mailbox access.
- Preserve important business data.

---

## Step 5: Remove Permissions

Access is removed from:

- Teams.
- SharePoint sites.
- Groups.
- Other company services.
