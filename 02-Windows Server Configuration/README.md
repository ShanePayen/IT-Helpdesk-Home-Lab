# Windows Server Configuration

## Overview

This section covers the preparation and configuration of the Windows Server virtual machine after it was created in Hyper-V.

The purpose of this stage was to prepare the server environment before installing Active Directory Domain Services.

---

## Completed Tasks

- Logged into Windows Server.
- Verified the server installation.
- Checked system information.
- Confirmed server identity.
- Prepared the environment for Active Directory installation.

---

## Tools Used

- Windows Server
- Server Manager
- PowerShell

---

## Skills Demonstrated

- Windows Server administration
- System verification
- PowerShell basics
- Server preparation
