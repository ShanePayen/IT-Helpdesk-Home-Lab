# User Management

## Overview

This section covers the creation and management of user accounts within the Active Directory environment.

The purpose of this stage was to simulate common helpdesk tasks involving employee accounts, permissions, and access management.

---

## Completed Tasks

- Created Active Directory user accounts.
- Managed user account properties.
- Assigned users to security groups.
- Verified account creation.
- Tested user administration processes.

---

## Tools Used

- Active Directory Users and Computers
- Windows Server
- PowerShell

---

## Skills Demonstrated

- User account administration
- Identity management
- Security group management
- Access control
- Helpdesk user support
